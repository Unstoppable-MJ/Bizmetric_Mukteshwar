Hotel Menu Bill Generator

A console-based Hotel Billing System developed using Python and SQL Server.
This application allows users to view the menu, place orders, generate bills, and store transaction records in a database.

Features

Load menu directly from SQL Server

Take multiple item orders

Automatic bill calculation

Store bill records in database

Clean and simple console interface

Modular class-based design

🛠 Technologies Used

Python

pyodbc

sql server management studio
